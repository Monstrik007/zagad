# Загадчики

Мультиплеерная мобильная игра в загадки по локальной Wi‑Fi сети.

## Как играть

1. Все игроки подключаются к **одной Wi‑Fi сети**.
2. Один игрок **создаёт комнату** (хост) и сообщает код комнаты или IP.
3. Остальные нажимают **«Войти в комнату»** — комната находится автоматически или по IP.
4. Хост выбирает режим и нажимает **«Начать игру»**.

### Режимы

- **Полная игра (от 3 игроков)** — босс загадывает слово, выбирает объясняющего, остальные задают вопросы и угадывают.
- **Короткая игра (от 2 игроков)** — босс загадывает и объясняет, второй игрок угадывает.

### Роли

| Роль | Действия |
|------|----------|
| **Босс** | Загадывает слово, выбирает объясняющего, отвечает на переданные вопросы, может завершить игру |
| **Объясняющий** | Видит слово, пишет объяснение, отвечает Да/Нет, может запросить конец игры |
| **Угадывающие** | Задают вопросы, пытаются угадать слово (без учёта регистра) |

В короткой игре роли **босс + объясняющий** совмещены у одного игрока.

## Запуск

```bash
flutter pub get
flutter run
```

## Сеть

Используется **локальная Wi‑Fi сеть** (TCP порт `45678`, UDP discovery `45679`). Bluetooth в первой версии не реализован.

Если комната видна, но подключение не удаётся (Linux-хост):

```bash
sudo ufw allow 45678/tcp
sudo ufw allow 45679/udp
```

Убедитесь, что в комнате отображается IP вида `192.168.x.x`, а не `172.17.x.x` (Docker).

## Требования

- Flutter 3.9+
- Android / iOS устройство или эмулятор в одной сети с хостом
